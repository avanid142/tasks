# 🚀 TaskFlow Ultimate

A modern and animated **Task Management Web Application** built using **Node.js, Express, HTML, CSS, and JavaScript** with authentication, task tracking, progress analytics, due dates, dark futuristic UI, and celebration animations.

---

# ✨ Features

## 🔐 Authentication
- Secure Login System using JWT
- Protected Dashboard Routes
- Cookie-based Authentication
- Logout functionality

---

## ✅ Task Management
- Add Tasks
- Delete Tasks
- Mark Tasks as Completed
- Real-time Task Updates
- Pending & Completed Task Tracking

---

## 📅 Due Dates
- Add Due Dates for Tasks
- Due dates displayed beside tasks
- Persistent task data during session

---

## 📊 Progress Analytics
- Dynamic Doughnut Progress Chart using Chart.js
- Real-time completion percentage
- Automatic progress updates

---

## 🎉 Celebration System
When all tasks are completed:
- Confetti Animation
- Celebration Popup
- Smooth UI Animations

---

## 🎨 Modern UI/UX
- Glassmorphism Design
- Dark Futuristic Theme
- Smooth Hover Effects
- Responsive Layout
- Animated Cards & Components

---

# 🛠️ Tech Stack

## Frontend
- HTML5
- CSS3
- JavaScript
- Chart.js
- Canvas Confetti

## Backend
- Node.js
- Express.js
- JWT Authentication
- Cookie Parser

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your username/tasks.git
```

---

## 2️⃣ Open Project Folder

```bash
cd tasks
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Run Server

```bash
node server.js
```
